# Workspace Rules

## Shell Configuration
- Always use **Git Bash** (`/usr/bin/env bash`) instead of PowerShell for all shell commands
- Use forward-slash Unix-style paths (e.g., `C:/Program Files/git/bin/bash.exe`) when referencing paths
- Run all shell commands through bash — avoid PowerShell syntax (`;`, `$env:Var`, `&&` chaining)
- Prefer POSIX-compatible commands over Windows-native equivalents where possible
